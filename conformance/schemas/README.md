# conformance/schemas — schemas, semantic rules, grammar differential

Machine-checkable reading of `docs/protocol-v0.3.md` for the publication
surface, run against blygger-studio (in process), a live studio node, and
blygger-desktop. Nothing here is normative: where the checker had to choose a
reading the spec leaves open, the choice is listed under **For Fable** in the
report.

```sh
cd conformance/schemas
npm install
node run.mjs              # everything: studio harness, live snapshot, desktop harness, validate, report
node run.mjs --offline    # same, reusing samples/live-*
node run.mjs --report-only
```

Outputs: `out/summary.json` (the toolkit's shared contract, every check
carrying `spec_refs`, `decisions` and `clauses` from
`conformance/clauses/clauses.json`) and `out/report.html` (self-contained).

Inputs it needs: `~/Code/blygger-studio` with its `node_modules` (override
with `STUDIO_DIR`), `~/Code/blygger-desktop` and the Rust toolchain it pins,
1.98.1 (override with `DESKTOP_DIR`), network for the live snapshot
(`LIVE_ORIGIN`, default `https://venkateshrao.com/blyg/`). Neither
implementation is modified: the studio is bundled from its own source with
its own esbuild and run under its own Miniflare, and the desktop crates are
path dependencies of `desktop-harness/`, built into `desktop-harness/target/`.

## Layout

| Path | What |
|---|---|
| `schemas/defs.schema.json` | Shared `$defs`: id, utc, reference (§5.9), cited, selector (§10.3), stub_of, generated entry (§5.7), changelog entry, author (opaque), media |
| `schemas/item.schema.json` | `items/{id}.json`, all kinds including the withdrawn endcap (§5, §9) |
| `schemas/pinned.schema.json` | `items/{id}/v{n}.json` (§8) |
| `schemas/manifest.schema.json`, `index.schema.json` | `blyg.json` (§6.1), `items/index.json` (§6.2) |
| `schemas/advisory.schema.json` | The SHOULD/RECOMMENDED layer. Its errors are warnings, never failures (decision #48) |
| `lib/semantic.mjs` | Cross-field rules JSON Schema cannot express, each tagged with level, § and decisions: hash, changelog contiguity, `updated`, absolute URLs in `content_html` (#53), directives ↔ `transclusions[]` ↔ baked wrappers (#26, #49), stub version agreement (#27), `forked_from.cited.url`, `page` form, `blyg-tk-gen` wrappers, pins served, … |
| `lib/grammar.mjs` | A reference reading of the §10.1 bracket grammar written from the spec, used by the rules |
| `lib/feed.mjs` | A small checker for the `blyg:` elements of `feed.xml` (§7) |
| `lib/selftest.mjs` | Mutation self-test: breaks one MUST in a good document and confirms the checker fails it |
| `grammar/*.json` | 27 grammar fixtures (`content_md` → expected parse), authored in `grammar/_source.mjs` |
| `harness/studio-run.mjs` | Boots blygger-studio in process, subscribes it to a fake remote blyg (`harness/fake-remote.mjs`, also a fake Anthropic endpoint), then makes fragment, thread, partial, stub (whole, partial, `{url}`), forks (remote thread, remote fragment, own pin), TK-generated and `impyrt` items, pins, withdrawals, a deleted image, and runs the grammar corpus through the real publish path |
| `harness/live-fetch.mjs` | Snapshots a live blyg's public surface into `samples/live-*` |
| `harness/desktop-run.mjs` + `desktop-harness/` | Runs the grammar corpus through `blyg_render::render_preview`, and every sampled item document through `blyg_core::api::public::ItemDoc` → `ReadingItem`/`Lineage`, reporting what a round trip drops |
| `samples/` | The documents validated (regenerated by `run.mjs`) |

## Levels

- **fail** — a MUST, or a schema constraint derived from one.
- **warn** — a SHOULD/RECOMMENDED, or a reading the spec leaves open.
- **info** — the spec is silent; recorded so it can be ruled.

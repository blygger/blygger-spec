# Technical notes

Numbered, non-normative documents recording design reasoning alongside the
spec — especially rejected designs and the rationale that closed them. Notes
constrain nothing; the spec is the only normative text. Published at
`blygger.org/notes/` (see `../spec-publishing-plan.md` §5).

Convention: `tn-{N}-{slug}.md`, numbered sequentially, never renumbered,
never deleted. First lines carry title (`# TN-{N} — …`), a bold status line
with date and attribution, and `current` status is implicit — a reversed
note instead gains a banner pointing at its successor.

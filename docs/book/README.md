# The book — manuscript

The Blygger protocol specification, rewritten to be read, toward 1.0. **A manuscript,
not the spec.** The living specification is [`../protocol-v0.4.md`](../protocol-v0.4.md)
and stays so until 0.5 opens. Nothing here is published.

Task, decisions and acceptance: [`../spec-refactor-plan.md`](../spec-refactor-plan.md)
(decision #109).

## Standing rules

- A 0.4 revision and its counterpart here are made in the same sitting.
- No rule changes in the book. A rule found wrong goes in `findings.md`.
- Examples are inline for now. Before a draft goes to implementers, each becomes a
  file the conformance suite validates.
